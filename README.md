# Rugramm — простой мессенджер

## Функционал
- Регистрация/авторизация
- Поиск пользователей
- Личные чаты
- Отправка сообщений в реальном времени

## Стек
- Backend: Node.js + Express
- Frontend: HTML/CSS/JavaScript
- Хранение: JSON-файлы (можно заменить на SQLite)

## Запуск
1. `npm install`
2. `node server.js`
3. Открой `http://localhost:3000`
